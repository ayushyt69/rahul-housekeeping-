# Product photo folders

Upload product photos into the matching category folder. The catalogue page reads these folders automatically; no JavaScript edits are needed when adding photos.

| Website category | Upload photos to |
| --- | --- |
| Cleaning & Housekeeping | `cleaning-housekeeping/` |
| Plastic Household Items | `plastic-household-items/` |
| Storage & Organisation | `storage-organisation/` |
| Chairs & Furniture | `chairs-furniture/` |
| Kitchen & Dining | `kitchen-dining/` |
| Bathroom Accessories | `bathroom-accessories/` |
| Other Household Products | `other-household-products/` |

Supported formats: JPG, JPEG, PNG, WEBP and GIF.

Photos already stored directly in this folder remain visible under **All Products**. New photos uploaded into a category folder appear under that category and under **All Products**.

Use clear filenames. Avoid uploading duplicate or unrelated images.
